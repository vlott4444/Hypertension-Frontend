# ЛР №5 — SPA «Стадии гипертонии»

React + TypeScript + Vite + React-Bootstrap. Интерфейс адаптирован под вертикальный экран телефона (420 px). Предметная область и медиа взяты из ЛР4 на Go/Gin.

## Запуск

Требуется Node.js 20+ и npm. В папке проекта:

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Проверка сборки: `npm run build`.

## Страницы и элементы

| URL | Экран | Кнопки / поля |
| --- | --- | --- |
| `/feed` | Лента: видео, название, описание, показатели САД/ДАД | «Далее» — переход к следующей mock-карточке с циклическим возвратом к первой |
| `/stages` | Плитка опубликованных стадий | Два ползунка «От / До» по систолическому давлению, «Сбросить», «Подробнее» в каждой карточке |
| `/stages/:id` | Подробная карточка | «Назад к плитке», изображение, видео либо заглушка |

Нижняя панель из 4 пунктов: **Лента** (доступна), **Добавить** (отключена), **Плитка** (доступна), **Вход** (отключен). Третья страница открывается кнопкой «Подробнее», а не через таб-панель.

## Данные, mock и медиа

Все текстовые данные карточек хранятся в `src/data/mock.ts` — шесть опубликованных записей с параметрами из сидера ЛР4 плюс седьмая демонстрационная запись с пустыми путями к медиа. Сервер не требуется; сетевых обращений к API при работе интерфейса **нет**. Реальные видеоролики и изображения ЛР4 находятся в `public/media/`.

Заглушка изображения хранится **в самом проекте**: `public/default-image.svg`. Если `image_name` пустое или изображение не загрузилось, компонент `StageImage` показывает её. Если `video_name` пустое/не читается, компонент `StageVideo` показывает изображение (при отсутствии изображения — ту же заглушку) с уведомлением. Демонстрация: открыть 7-ю карточку на `/stages/7` или пролистать ленту до 7-й карточки.

## Компоненты, props, хуки

- `StageCard` принимает `stage: HypertensionStage` как prop и рисует карточку.
- `StageFilter` принимает `minBP`, `maxBP`, обработчики `onMinChange`, `onMaxChange`, `onReset` как props.
- `GridPage` использует `useState` для двух границ и фильтрует локальный массив, не делая `fetch`.
- `FeedPage` использует `useState` для индекса текущей карточки.
- `GridPage` и `FeedPage` используют `useEffect` для заголовка вкладки и очистки после размонтирования.
- `StageImage`/`StageVideo` используют `useState` для обнаружения ошибок загрузки медиа.
- `DetailPage` использует `useParams` для чтения id из URL.
- `BottomNav` использует `NavLink` для отображения активной вкладки.
- Redux и `React.createContext` **не используются**.

## Network и 10 скриншотов для защиты

Открыть DevTools → Network, включить фильтр All. Для локального mock ожидаются запросы к статическим JS/CSS, изображениям и видео, **но не к API**. Снимки:

1. `/feed` плюс Network.
2. `/stages` плюс Network.
3. `/stages/4` плюс Network.
4. `src/components/StageMedia.tsx`, логика `StageImage`.
5. `/stages/7`: заглушка изображения и видео.
6. `src/components/StageFilter.tsx`, интерфейс props.
7. `src/pages/GridPage.tsx`, передача props и `.filter()`.
8. `useState` в `GridPage`/`FeedPage`.
9. `useEffect` в `GridPage`, `useParams` в `DetailPage` и хуки медиа.
10. Данный README.

## Веб-сервис ЛР4

Приложение подготовлено для последующего подключения Go API (в `vite.config.ts` есть proxy `/api` → `localhost:8080`), но **по требованию mock-этапа данные не запрашиваются**. Реальное API-подключение нужно реализовывать отдельно, если преподаватель попросит показать взаимодействие с Go.

## Оформление оригинальной ЛР4

Стили React-приложения перенесены из `resources/styles/hypertension.css` оригинальной ЛР4. Сохранены бордово-розовая палитра, карточки в два столбца, сердечки на ползунках, нижняя скруглённая навигация, видео-лента, затемнение, «Далее» и «ещё / свернуть». Четыре вкладки вместо трёх соответствуют заданию ЛР5; «добавить» и «вход» отключены. Фильтр применяется кнопкой «Применить», как в ЛР4.
