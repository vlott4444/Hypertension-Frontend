# ЛР6 — Backend

Go/Gin API из ЛР4, дополненный JWT HS256, bcrypt, Redis blacklist, фильтрами и загрузкой в MinIO. Полная инструкция по запуску в **README.md корня архива**.

Миграции и seed выполняются автоматически при запуске контейнера `backend`. Только для локальной учебной демонстрации.

Исходные медиа из ЛР4 теперь лежат в `frontend/public/media`, едином каталоге для mock и загрузки образцов в MinIO. При Docker-сборке они копируются в `/app/resources/media`.
