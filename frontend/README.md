# ЛР6 — Frontend

Это фронтенд единого проекта. Для запуска используйте **README.md в корне архива** и `docker compose up --build -d`.

React + Vite + TypeScript + Redux Toolkit/Thunk + Axios, авторизация, фильтры, лента, создание, удаление, лайки.

Для автономной проверки mock без Docker: `npm install && npm run dev` (гостевой режим, бэкенд недоступен).
